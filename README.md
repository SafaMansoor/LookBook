# Fashion Recommendation System

A fashion recommendation system using ResNet50 and Nearest Neighbors.

## Features

- Upload an image
- Extract deep features using ResNet50
- Recommend similar products

## Tech Stack

- Python
- TensorFlow
- Streamlit
- Scikit-learn

## Dataset

Kaggle Fashion Product Images Dataset

## Note
The dataset and generated files (`embeddings.pkl` and `filenames.pkl`) are not included in this repository because they exceed GitHub's file size limit.
